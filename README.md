# Visuels Causette

Images des publications réseaux sociaux, servies **par URL** à Buffer et Metricool.
Dépôt public **par nécessité technique** : ces deux outils n'acceptent pas un fichier.

Rien d'autre n'a sa place ici — ni code, ni clés, ni listings.

Produites par `banque_visuels.py` (Brand System Causette v1.3).
Sélection à la publication : `rotation.py`, dans le dépôt des routines.

Base d'URL : `https://raw.githubusercontent.com/meedrendir/causette-visuels/main/EXPORTS/`
